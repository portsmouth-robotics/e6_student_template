## When you have finished your work

Before leaving the lab:

- [ ] Save all open files in VS Code.
- [ ] Open the **Source Control** panel.
- [ ] Review your changes.
- [ ] Commit your changes with a clear message.
- [ ] **Push / Sync Changes** to GitHub.
- [ ] Check GitHub to make sure your latest commit is visible online.
- [ ] Close any running ROS 2 programs and terminals.
- [ ] Sign out of GitHub in VS Code.
- [ ] Sign out of any other accounts you used on the lab PC.
- [ ] Close VS Code and any other applications you opened.

**Do not rely on files being left only on the lab PC. Your work should be pushed to GitHub before you leave.**
